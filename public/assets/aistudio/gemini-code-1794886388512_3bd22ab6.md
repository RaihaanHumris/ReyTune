# Design System & UI/UX Specification
**Proyek:** OfflineTune  
**Pendekatan:** Mobile-First, Dark-Mode Native, Minimalist Audio Interface  

---

## 1. Filosofi Desain
Antarmuka dirancang dengan pendekatan **Dark-Mode First** untuk mengurangi kelelahan mata saat digunakan di malam hari atau saat bepergian, sekaligus menonjolkan visual *album artwork*. Fokus utama adalah aksesibilitas satu tangan (kontrol utama berada di area jempol bagian bawah).

## 2. Palet Warna (Color Tokens)

| Token | Hex | Penggunaan |
| :--- | :--- | :--- |
| `--bg-primary` | `#0B0F17` | Latar belakang utama aplikasi |
| `--bg-secondary` | `#131A26` | Kartu lagu, modal, dan *bottom sheet* |
| `--bg-elevated` | `#1E293B` | *Mini player*, *hover state*, dan input pencarian |
| `--accent-primary` | `#10B981` | Tombol Play utama, indikator aktif, status *Downloaded* |
| `--accent-hover` | `#059669` | *Hover/active state* tombol utama |
| `--text-primary` | `#F8FAFC` | Judul lagu, header utama |
| `--text-secondary` | `#94A3B8` | Nama artis, durasi lagu, sub-teks |
| `--border-subtle` | `#1E293B` | Garis pemisah tipis antar elemen |
| `--status-danger` | `#EF4444` | Hapus unduhan, status gagal unduh |

## 3. Tipografi
- **Font Family:** `Plus Jakarta Sans` atau `Inter` (Sans-serif modern, keterbacaan tinggi pada layar kecil).
- **Skala Ukuran:**
  - **Page Title:** `24px` / Bold (`700`)
  - **Section Heading:** `18px` / Semi-Bold (`600`)
  - **Track Title:** `15px` / Medium (`500`)
  - **Artist / Metadata:** `13px` / Regular (`400`)
  - **Micro Label (Durasi / Ukuran File):** `11px` / Medium (`500`)

## 4. Layout & Struktur Navigasi

### 4.1. Bottom Navigation Bar (Mobile) / Sidebar (Desktop)
Terdiri dari 3 menu utama:
1. **Eksplorasi (Explore):** Pencarian lagu *online* & daftar rekomendasi.
2. **Koleksi (Library):** Tab filter untuk **Semua Unduhan**, **Playlist**, dan **Disukai**.
3. **Pengaturan (Settings):** Manajemen kapasitas penyimpanan, kualitas audio unduhan, dan hapus *cache*.

### 4.2. Persistent Mini Player
Melayang tepat di atas *Bottom Navigation Bar* (`height: 64px`) dengan efek *glassmorphism* (`backdrop-filter: blur(12px)`):
- **Kiri:** Thumbnail *cover art* (`44x44px`, `rounded-md`) + Judul lagu & Nama artis (teks berjalan/*marquee* jika terlalu panjang).
- **Kanan:** Tombol `Play/Pause` dan tombol `Next`.
- **Atas:** Garis progres tipis (`2px`) di tepi atas *mini player*.

## 5. Spesifikasi Komponen Kunci

### 5.1. Track List Item
- **Tinggi:** `64px`
- **Elemen:**
  1. Nomor urut atau *Cover Art* (`48x48px`, `border-radius: 8px`).
  2. Blok teks: Judul Lagu (`--text-primary`) di atas Nama Artis (`--text-secondary`).
  3. **Status Badge Offline:** Ikon centang hijau kecil (`14px`) di samping nama artis jika lagu sudah tersimpan *offline*.
  4. **Action Button:**
     - Jika belum diunduh: Ikon `Download` (`lucide-react: ArrowDownToLine`).
     - Jika sedang mengunduh: *Circular progress ring* dengan persentase.
     - Jika sudah diunduh: Ikon `More Vertical` (opsi: Tambah ke Playlist, Hapus Unduhan).

### 5.2. Full-Screen Player (Now Playing)
Dibuka saat pengguna mengetuk *Mini Player*:
- **Header:** Tombol *minimize* (panah ke bawah), label sumber pemutaran (misal: *"Memutar dari Koleksi Offline"*), dan tombol opsi.
- **Artwork:** *Cover art* besar (`aspect-square`, `max-width: 320px`, `border-radius: 16px`, bayangan lembut).
- **Info & Aksi Cepat:** Judul lagu, nama artis, tombol *Like* (hati), dan tombol *Download / Offline Status*.
- **Scrubber / Seekbar:** Slider interaktif dengan label waktu berjalan di kiri dan total durasi di kanan.
- **Kontrol Utama:** `Shuffle` — `Previous` — `Play/Pause` (lingkaran besar `64px` warna `--accent-primary`) — `Next` — `Repeat`.

### 5.3. Indikator Offline Banner
- Saat koneksi terputus, muncul *pill banner* halus di bagian atas layar: `"Mode Offline Aktif • Menampilkan lagu tersimpan"` dengan warna latar `#1E293B` dan teks `#10B981`.

## 6. Interaksi & Micro-Animations
- **Audio Visualizer Mini:** Animasi 3 batang equalizer bergerak pada *cover art* lagu yang sedang aktif diputar.
- **Download Feedback:** Saat unduhan selesai, ikon progres bertransisi halus menjadi ikon centang hijau dengan *toast notification* singkat di bagian atas.
- **Skeleton Loading:** Gunakan *shimmer skeleton* saat memuat hasil pencarian *online* agar tata letak tidak melompat (*zero layout shift*).
